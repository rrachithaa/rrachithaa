## 🚀 Featured project

### 🐕 Quadruped Robot: LiDAR Obstacle Avoidance
A 12-DOF quadruped built from scratch in **ROS 2 Humble + Gazebo Fortress**. It walks around walls and obstacles on its own using a 2D LiDAR.

<div align="center">
<img src="https://raw.githubusercontent.com/rrachithaa/quadruped-lidar-obstacle-avoidance/main/assets/demo_lidar.gif" width="640" alt="Quadruped avoiding obstacles using LiDAR"/>
</div>

- Custom URDF/xacro model with `ros2_control` for 12 joints
- Own leg **inverse kinematics** and **trot gait** in Python
- `/cmd_vel` interface for forward, backward and turning
- Gazebo `gpu_lidar` bridged to ROS 2 (`/scan`) with a reactive obstacle-avoidance node
- Simulated obstacle arena with walls, boxes and cylinders

`ROS 2` `Gazebo` `ros2_control` `Python` `LiDAR` `RViz`

👉 **[View the repository](https://github.com/rrachithaa/quadruped-lidar-obstacle-avoidance)**
